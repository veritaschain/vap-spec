# 証拠レビュー用レポートの作成・再検証

このツールは、保存済みの合成実験53ケースを再検証し、元の記録までたどれる
日本語・英語のMarkdownとJSONを作ります。53件という数字は、安全性を確認した
件数や事故を防止した件数ではありません。人によるレビューも実施しません。

## 読むときの区別

| 表示 | 意味 |
|---|---|
| 保存済みケースの再検証完了数 | 元の検証関数で証拠の署名・結び付け・判断・一覧を再検証した数 |
| シナリオの期待値一致 | 合成実験で予定した結果と記録が一致したこと。迂回や残存データを観測する負の対照も含む |
| 記録された操作状態・観測 | 元の管理主体が記録した状態。今回その操作を再実行したものではない |
| `UNKNOWN` | 元の評価で結果が不明とされたこと |
| `NOT_ESTABLISHED` | 元の評価で成立が確認されていないこと |
| `NOT_ASSESSED` | 評価していないこと |
| `FRAME_NOT_RECORDED` | 対応する評価フレームが記録されていないこと。架空の不明値を補わない |

各事実には、元JSONのファイル、**生のバイト列のSHA-256**、JSON Pointerを付けます。
前段階の許可、実行直前の最終判断、実行後の評価は別々に表示します。管理経路が
拒否した記録と迂回経路での操作、対象エントリの削除と別コピーの読み出しなども、
一方を消さずに並べます。

## 1. 信頼するソースと入力を用意する

レビュー済みのチェックアウトを使用します。このレポーターは、前段の固定キットの
実行入力136ファイルを照合してから、その検証コードを読み込みます。元キットや
パイロットを別の版へ置き換えた場合は失敗します。

入力には[元キットの手順](../incident-recheck-kit/RUN-ja.md)で得た
`incident-ci-2026-10-30.zip`を指定します。GitHubから取得する外側の成果物ZIPとは
区別してください。対応する入力キットの期待SHA-256は次のとおりです。

```text
06bdb46eade7ef5c2f041797007d1f7ef3aaa55ad17d88a90b28276be17d865f
```

## 2. 依存関係を明示的に導入する

Linux、Python 3.12または3.14を使用します。導入はオフライン再検証とは別の操作です。

```sh
cd experiments/incident-review-report
python3 -m venv .venv
.venv/bin/python -m pip install --only-binary=:all: -r requirements.txt
```

レポーターは依存関係を自動取得せず、外部サービスにも接続しません。Python本体や
依存バイナリ、ローカル環境への信頼は残ります。子プロセスの監査フックはOS隔離
ではありません。

## 3. 新しいレポートを作る

出力先の親ディレクトリは先に用意します。既存ファイル・ディレクトリ・シンボリック
リンクは上書きしません。

```sh
.venv/bin/python -m incident_review build \
  --archive /absolute/path/incident-ci-2026-10-30.zip \
  --expected-sha256 06bdb46eade7ef5c2f041797007d1f7ef3aaa55ad17d88a90b28276be17d865f \
  --output /absolute/path/new-review.zip
```

元の53ケースすべてを実際に再検証してから、固定された4ファイルを持つZIPを
作成します。JSONが構造化された本体、日本語・英語Markdownが閲覧用、manifestが
各ファイルのハッシュと長さです。生成した日時や出力先は内容に含めず、同じソースと
入力から同じバイト列になります。元の送信・公開・削除操作は実行しません。

## 4. 受け取ったレポートを再検証する

`EXPECTED_REPORT_HEX`は、受け取ったZIPの外にある確認済みの実行結果から取得します。

```sh
.venv/bin/python -m incident_review verify \
  --archive /absolute/path/incident-ci-2026-10-30.zip \
  --expected-sha256 06bdb46eade7ef5c2f041797007d1f7ef3aaa55ad17d88a90b28276be17d865f \
  --report /absolute/path/received-review.zip \
  --expected-report-sha256 EXPECTED_REPORT_HEX
```

ZIP自身のチェックサムだけを信用せず、元の証拠を再検証して期待するレポートを
作り直し、全バイトを比較します。表示の結論や内部manifestを書き換えても、この
照合には通りません。候補ZIP内のコードを実行したり、そのZIPを展開したりする
処理はありません。

生成レポートの読みやすさは、証拠の効力を広げません。独立した観測や再現、人の
審査、完全削除、開示義務の充足、VAP適合性、法令遵守はいずれもこの処理で
証明・認定する対象ではありません。
