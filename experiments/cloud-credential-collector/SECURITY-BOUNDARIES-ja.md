## 背景と情報の帰属

WorkOSの11月6日の更新は、10月のアクセスを研究者のARTEX評価用エージェントに帰属させ、APIの外部公開、弱い開発用認証情報、検知の遅れを報告しています［S1］。ここではWorkOSの説明を記録しており、逸脱の技術経路や意図を独立に立証していません。Claude Codeの公式文書には、永続的な承認ルールとローカル設定に対するユーザー単位のglobal Git excludesが記載されています［S2、S3］。Apiiroの事件に関する集計値は、一次資料の確認待ちとして掲載を保留しています［S4］。

## 実行時の境界に関する提案

実環境の認可制御では、実行前に、信頼を確立した実行主体と委譲元のID、テナント、環境、正確な宛先と操作、ポリシーの版、有効期限、nonce・再利用の状態、現在の失効状態を確認する設計が考えられます。これらは導入時の入力に関する提案であり、新たな規範フィールドではありません。

本実験とは別の制御層で、実際に名前解決された接続先と、リダイレクトや委譲された操作の各段階を許可範囲と照合し、承認した宛先と接続を結び付けます。認証情報が使えることによって、サンドボックスの許可範囲が本番へ広がるわけではありません。宣言された意図、認可判断、観測した操作・結果は区別します。観測が欠ければ証拠は未解決のままです。証拠を取得できないため今後の実行を拒否する運用は可能ですが、過去の操作が拒否された、または起きなかったという証拠を作ってはなりません。

## 機密性の境界に関する提案

共有する承認記録、コマンドログ、結果に生の認証情報を含めません。秘密値の代わりに、それを含まない不透明な認証情報IDや鍵のバージョンIDを使用します。候補が少ない秘密値の単純なハッシュは、候補を照合して推測できる場合があります。base64、通常のハッシュ、署名は機密性を提供しません。原本全体のダイジェストであっても、残りの内容が予測可能なら、秘密値の推測を可能にする場合があります。

共有用の記録は署名前に必要最小限へ絞ります。必要な生の原本は、アクセスと保持の方針に従い、アクセスを制限した保管先で別途保持します。秘匿化した派生ビューには別の識別と署名を付け、変換内容と原本との関係を説明します。公開により推測が可能になる原本のダイジェストなど、機微な対応関係は公開せず制限付きで管理します。原本を書き換えたり、変更後のバイト列に原本の署名を流用したりしません。派生ビューの署名が認証するのはそのビューの記述であり、省略した証拠を復元するものではありません。

## 現行実装の限界

コレクターは原本のバイト列をそのまま保持します。PACKは原本と署名済みの保管履歴メタデータを出力し、ローカルファイルには非公開の権限を設定します。どちらも、**秘密情報のスキャン、秘匿化、暗号化、受領者の認可、公開・提供の可否判断、実行前の認可ゲートを提供していません**。ローカルのファイル権限は、受領者が後から作るコピーを管理しません。保管履歴の検証に成功しても、配布を許可したことにはなりません。

秘匿化した開示用ビューは、現行PACKの機能ではありません。原本やそのコミットメントを共有できない場合はパックの提供を保留し、パックを黙って編集しません。配布には別途レビューと認可が必要です。

別の[実行前記録ゲート実験](../pre-record-gate/README.md)には、承認した操作との厳密な比較と、リダイレクトを含む合成環境の通信制限があります。[OS隔離実験](../os-isolated-gate/README.md)は限定した経路を検証し、[消費者向けエージェント証跡の提案](../../proposals/consumer-agent-evidence/README.md)は主体、委譲、対象範囲を扱っています。クラウドコレクターもテナント・リソースの文脈を束縛し、保管履歴の完全性を確認します。

これらの部品ごとの確認は、実環境の認可や機密情報の提供制御として組み合わせた全体の成立を示しません。**次の6件は、本コレクター／PACK実験では確立していない導入・共有用ビューの受入条件です。本作業で新たにテストした結果ではありません。** すべての基礎的なチェックが存在しないという意味ではありません。

## 将来の導入・共有用ビューで確認する条件

| ケース | 今後実証する挙動 | 状態 |
| --- | --- | --- |
| サンドボックスの承認で本番を指定 | 実行前に環境・許可範囲の不一致を拒否する。 | 本実験では未確立 |
| リダイレクトまたは外向き通信先の変更 | 解決された宛先と委譲操作を再確認し、各接続を承認範囲に結び付ける。 | 本実験では未確立 |
| 観測の欠落 | 証拠を未解決のまま扱い、ポリシーによる拒否と観測した過去の結果を区別する。 | 本実験では未確立 |
| argv・ヘッダー・承認・結果内の秘密情報 | 各テスト用秘密値を共有記録やエラー出力に含めず、必要な原本は別途制限付きで保持する。 | 本実験では未確立 |
| 受領者の権限不足 | 保管履歴の検証に成功しても提供を拒否する。 | 本実験では未確立 |
| 変更された原本と署名済み派生ビュー | コミット済みのバイト列の変更を拒否し、明示的に識別・別途署名した派生ビューは、それ自身の文脈と信頼に基づいて検証する。 | 本実験では未確立 |

これらの提案は、VAP/VCPによる防止効果、導入、適合性、本番利用の準備完了を確立しません。
