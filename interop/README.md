# VAP Interoperability

This directory holds executable contracts and test vectors used to determine
whether independently developed tools interpret VAP evidence consistently.

## Current work

- [`vap-evidence-pack-demo/`](./vap-evidence-pack-demo/) — profile-neutral
  third-party verification demo covering signed decision events, Merkle
  collection integrity, scope commitments, completeness invariants,
  cross-party receipts, and offline verification.

Interoperability results are evidence of technical compatibility. They do not
constitute certification or endorsement by VSO.
